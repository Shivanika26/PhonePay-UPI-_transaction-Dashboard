# 📊 PhonePe UPI Transaction Dashboard

An interactive Excel dashboard designed to analyze UPI transaction data and provide clear insights into transaction performance, spending patterns, customer demographics, cashback, and suspected fraud.

## 🖥️ Dashboard Preview

![PhonePe UPI_dashboard](PhonePe_UPI_dashboard.png)

## 📌 Key KPIs

- Total Transactions: 5,02,887
- Total Transaction Amount: ₹44.25 Crore
- Total Cashback: ₹34.63 Lakh
- Transaction Success Rate: 91%
- Suspected Fraud Transactions: 17,089

## 📈 Dashboard Analysis

The dashboard provides insights into:

- UPI application-wise transaction distribution
- Total spending by merchant category
- Transaction volume by age group and gender
- Transaction success and failure analysis
- Fraud risk and suspected transaction analysis
- State-wise transaction activity
- Cashback and transaction performance

## 🔍 Key Insights

- PhonePe has the highest transaction share at approximately 48%.
- Google Pay contributes around 22% of transactions.
- Paytm contributes around 15% of transactions.
- The overall transaction success rate is 91%.
- 17,089 transactions are identified as suspected fraud.
- The 25–34 age group shows the highest transaction volume.
- Shopping, Utilities, Healthcare, Fuel and Financial Services are among the major merchant categories.
- The state-wise analysis highlights differences in transaction activity across India.

## 🛠️ Tools Used

- Microsoft Excel

- Data Analysis

## 🎯 Project Objective

The objective of this project is to transform raw UPI transaction data into an interactive dashboard that helps users understand transaction trends, customer behavior, merchant spending, payment success, and potential fraud risks.
